# 🛡️ CyberGuard

> **Detect. Test. Learn. Stay Safe.**

CyberGuard is a **phishing detection and cybersecurity awareness platform** designed to help users identify suspicious links while also testing how they respond to potential phishing attempts.

Instead of only telling users whether a URL is safe or suspicious, CyberGuard combines **phishing detection with an interactive security-awareness test**, helping users understand how easily a phishing attempt can affect their security score.

---

## 🚨 What is CyberGuard?

Phishing attacks often rely on users clicking a link without checking whether it is trustworthy.

CyberGuard approaches the problem from two sides:

🔍 **Detection** — Analyze a URL and determine whether it appears safe or suspicious.

🧪 **Awareness Testing** — Simulate phishing/spam scenarios and observe how the user responds.

📊 **Security Score** — Track the user's security awareness through a score that changes based on their actions.

📧 **Spam Alerts** — Send simulated alerts that allow the user to experience a phishing scenario in a controlled environment.

---

## ✨ Features

### 🔍 Phishing Link Detection

Enter a URL and CyberGuard analyzes it to determine whether it appears:

- 🟢 Safe
- 🟡 Suspicious
- 🔴 Potentially Phishing

The result is accompanied by a risk/security score to make the result easier to understand.

---

### 🧪 Phishing Awareness Test

CyberGuard doesn't stop at detection.

Users can be tested with simulated phishing or spam scenarios to see how they respond.

The goal is to turn cybersecurity awareness into something **interactive rather than purely theoretical**.

---

### 📧 Simulated Spam Alerts

CyberGuard can send a simulated spam/phishing alert to the user.

The user can interact with the alert just as they might encounter a suspicious message in real life.

> ⚠️ These scenarios are designed for controlled security-awareness testing.

---

### 📊 Security Awareness Score

CyberGuard maintains a security-awareness score.
